한 달에 자유롭게 운영할 수 있는 총 금액을 입력해 줘. 아래 고정지출을 제외한 돈이 일별로 배정돼.

저축

선택한 달의 저축 금액은 고정지출과 별도로 월 예산에서 차감해. 기본 저축액을 저장한 뒤 추가·감액할 금액만 입력할 수 있어.
저축금액 추가·감액

이번 달 예산 추가·조정

날짜와 사유를 함께 기록해. 추가 예산은 양수로, 예산 감액은 음수로 입력하면 돼. 월 합계와 일일 사용 가능 금액은 즉시 반영돼.

고정지출 관리

월세·구독·통신비 등의 지출 날짜와 사유를 적어 줘. 선택한 월의 예산에서 한 번만 차감되며 달력에 다시 입력하지 않아도 돼.

저축통장

월이나 연도와 관계없이 모든 달에 등록된 저축액을 합산해. 해당 달의 저축금액을 수정하면 합계와 아래 표도 자동으로 바뀌어.

저축은 실제 은행 계좌와 연결되어 있지 않은 가계부상의 기록이야. 다른 지출과 중복 차감하지 않도록 관리해 줘.

데이터 백업 및 복원

정보는 이 기기의 브라우저에만 저장돼. 저축 기록도 JSON 백업에 포함돼. 브라우저 데이터를 지우거나 기기를 변경하기 전에 꼭 백업 파일을 보관해 줘.

복원하면 현재 기록은 백업 파일의 데이터로 대체돼. 중요한 기록을 먼저 내보내기 해 줘.

② 달력에서 날짜를 터치하고 지출 입력
③ 홈에서 오늘의 사용 가능 금액과 남은 돈 확인
④ 변경된 예산과 지출을 기준으로 하루 금액 자동 갱신
